## 服务器管理

以 unitree 用户登录后执行：

```sh
cd /home/unitree/lan-chat-ubuntu-amd64
docker compose ps
docker compose logs --tail=100 chat
docker compose exec -T chat /lanchat healthcheck
docker compose stop       # 暂停
docker compose start      # 恢复
docker compose restart   # 重启
```

不要执行 `docker compose down -v`，以免删除聊天数据。备份方法见包内部署说明。

## 安装补充

原服务器已有 Docker 27.5.1，但缺少 Compose。已从 Docker 官方 Ubuntu 软件仓库包安装用户级 Compose v5.1.1，路径为 `/home/unitree/.docker/cli-plugins/docker-compose`，未升级 Docker Engine 或修改现有其他容器。

软件源原配置引用不可用的 127.0.0.1:3128 代理。没有改动代理配置；官方包在开发机下载，经软件源公布的 SHA-256 校验后上传，离线提取插件。

原发布配置丢弃所有 Linux capabilities，导致 UID 0 容器无法读取 UID 1000 拥有且权限 0600 的挂载私钥。已在该文件上添加 UID 0 只读 ACL，所有者保留读写权限，所属组及其他用户无读取权限；CA 私钥不授权、不挂载。容器保留 `cap_drop: ALL`、无 `cap_add`、私钥只读挂载、只读根文件系统和 no-new-privileges。证书生成脚本会在续期时重新设置此 ACL，非 root Linux 用户需安装 acl 工具；服务器已具备该工具。可通过 `getfacl certs/server.key` 查看实际授权。此修正已同步源码、发布配置与部署包。
