# 多频道与提示音（已确认需求）

允许已登录用户创建、命名频道。默认公共频道接收旧数据；频道和消息持久保存。每个频道的文字、录音、在线名单、群语音独立，每频道语音最多五人。所有频道共用原有 UDP/TCP 端口，但使用独立转发音轨。切换频道退出本页面通话并取消录音；其他标签页的通话不被误关闭。

实时新消息仅向当前频道推送。语音连接成功、退出或断开时，该频道所有在线用户均收到独立事件并播放提示音，包括未参加通话者。历史加载、刷新名册、文本频道进出不发提示音。提供提示音开关和浏览器播放解锁入口；手机系统挂起网页时无法保证提示。

实施步骤：
1. SQLite 可重复执行迁移，公共频道承接旧消息；频道创建和名称校验；按频道查询历史、发送文字/录音。
2. WebSocket 按频道分组，语音房间共享网络资源但音轨隔离；真实连接事件与名册更新分开。
3. 手机/桌面频道选择与创建；切换时清理异步状态；提示音及开关。
4. 数据迁移、接口隔离、真实 RTP 隔离、浏览器切换/消息/录音/语音通知测试；独立代码复核。
5. 服务器备份数据后更新镜像，保留 CA、证书与卷；远程冒烟验证；刷新 amd64 离线包和部署说明。

重点回归：旧库迁移/重启持久化；同名及非法名称；延迟历史响应不可串频道；多标签页退出安全；其他频道无消息或语音提示；新进页面不误播放名册提示。
